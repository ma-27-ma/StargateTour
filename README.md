# 🚀 StargateTour

**StargateTour** is a fictional startup project focused on **intergalactic travel**, created as a front-end web development project.

The website presents a futuristic travel experience where users can explore different galactic destinations and calculate the price of their journey using **STR (Stellar Travel Rate)** as the fictional currency.

## 🌌 Project Overview

StargateTour combines a fictional travel agency concept with an interactive price calculator.

Users can select a destination, choose the number of passengers, and calculate the total cost of their galactic journey. The calculator also includes a discount when purchasing travel for **3 or more passengers**.

### Destinations

* Mars — 1,490 STR
* Saturn — 2,350 STR
* Europa — 1,990 STR
* Milky Way Deluxe — 3,490 STR
* Orion Nebula — 4,250 STR
* Event Horizon — 5,990 STR
* Andromeda Explorer — 6,490 STR
* Comet Route — 2,890 STR
* Saturn Rings Luxury — 4,990 STR

## 🧮 Price Calculator

The calculator allows users to:

* Select a galactic destination
* Enter the number of passengers
* Calculate the journey price
* Display the subtotal
* Apply the corresponding discount
* Display the final total

The calculations and interactions are handled with JavaScript.
